# Sunglass product photos go here

Same structure as `/assets/images/eyeglass-20/README.md` — see that file for
the full explanation of the 5-photo set, format and overlay notes.

## File naming

```
sunglass-<gender>-<number>-front.webp
sunglass-<gender>-<number>-left.webp
sunglass-<gender>-<number>-right.webp
sunglass-<gender>-<number>-side-left.webp
sunglass-<gender>-<number>-side-right.webp
```

Example:

```
sunglass-men-01-front.webp
sunglass-men-01-left.webp
sunglass-men-01-right.webp
sunglass-men-01-side-left.webp
sunglass-men-01-side-right.webp
```

Optional AR overlay: `sunglass-men-01-overlay.png` (transparent PNG, front
view only).

Register new frames in `/assets/data/sunglasses.json` — see
`/assets/data/PRODUCT_SCHEMA.md` for the field-by-field schema.
